## COMO GERAR O QR CODE (passo a passo para o comprador)

**Para abrir uma conversa com a loja (placas 1, 2, 4, 5, 7 e 8):**
1. Monte o link assim: `https://wa.me/55DDDNUMERO?text=MENSAGEM`
   - Exemplo: `https://wa.me/5521999999999?text=Quero%20receber%20as%20ofertas%20do%20a%C3%A7ougue`
   - Escreva o número só com algarismos: 55 + DDD + número, sem espaço, traço ou parênteses.
   - Dica: escreva a mensagem normalmente no Canva ou no gerador; muitos geradores convertem os espaços sozinhos.
2. No Canva: **Apps → QR Code** → cole o link → o código aparece na arte.
3. **Teste com o seu próprio celular antes de imprimir.**

**Para o grupo de ofertas (placa 3):**
1. No WhatsApp, abra o grupo → **Convidar via link** → copie o link.
2. Cole o link no gerador de QR Code do Canva.

**Para o Instagram (placa 6):**
- Use o link `https://instagram.com/perfildaloja`, ou o QR Code do próprio Instagram (Perfil → menu → QR Code).

## ESPECIFICAÇÃO DE DESIGN (para criar as placas)
- Mesma identidade dos 15 modelos do kit (fontes Montserrat/Bebas Neue, 3 cores editáveis).
- QR Code com **no mínimo 4 cm × 4 cm** impresso, sobre fundo branco e com margem branca em volta.
- Título em letras grandes, legível a 2 metros de distância.
- Seta ou ícone de celular apontando para o QR Code.
- Espaço para o logo da loja no rodapé.
- Dica de impressão no PDF: *"Plastifique ou use papel couchê para durar mais no balcão."*
